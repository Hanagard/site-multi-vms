# Multi VMS — site institucional

Site estático responsivo para apresentar a plataforma Multi VMS.

## Arquivos

- `index.html`: conteúdo e estrutura do site
- `styles.css`: identidade visual e layout responsivo
- `script.js`: menu móvel e ano do rodapé
- `assets/`: capturas do software extraídas da apresentação comercial

## Prévia local

Abra `index.html` no navegador. Não há etapa de build nem dependências de instalação.

## Publicação com GitHub Pages

Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)` para publicar o site.
